## Установка и запуск в режиме разработки:

1) Скопировать и заполнить .env файл в зависимости от окружения (шаблон .env.example);
2) Установить зависимости (без выполнения npm-хуков) ```npm run first-install```;
3) Сбилдить common-проект ```npm run build:common```;
4) Поднять инфраструктуру (Docker) ```npm run docker:up```:
   - Положить лицензию в `docker/minio/minio.license` (в git не коммитится);
   - MinIO API `http://localhost:9000`, MinIO Console `http://localhost:9001`, 
   - Postgres `localhost:5432`; 
   - Данные лежат в `./volumes/minio` и `./volumes/postgres`;
5) Запустить бэкенд ```npm run dev:backend```;
6) Запустить фронтенд ```npm run dev:frontend```;

## Установка и запуск в Docker (production-сборка, без SSL):

1) Заполнить `.env.production` (можно скопировать с `.env.local`);
2) Инфраструктура: ```npm run docker:up```;
3) Собрать и запустить app: ```npm run docker:app:up```;
4) Открыть фронт на `FRONTEND_PORT`, API на `BACKEND_PORT` из `.env`;
5) Остановить app: ```npm run docker:app:down```;

## Версии приложения

### 0.1.* - MVP _(текущая версия)_

- Полноценный адаптивный интерфейс приложения со светлой темой и русским языком.
- Одно общее пространство для работы с изменениями в реальном времени (websocket-соединение);
- Базовые действия с досками, колонками и задачами: просмотр, создание, редактирование, удаление, перемещение;

### 0.2.* - Пользователи _(в разработке)_

- Регистрация полноценного аккаунта с подтверждением Email;
- Альтернативная регистрация тестового аккаунта (без подтверждения данных) с ограничениями: нельзя пригласить в
  пространство, пользовательские данные и данные для входа генерируются системой, восстановление данных входа
  невозможны, редактирование пользовательских данных невозможно, аккаунт удаляется через 24 ч;
- Восстановление утраченных данных;
- Изолированное пространство для работы для каждого аккаунта (до 5 досок на аккаунт);
- Возможность приглашать пользователей в пространство для совместной работы по инвайт-ссылкам (регистрируется полный
  аккаунт);
- Ролевая система пространства: owner, user;
- Гибкая система разрешений и доступов для пользователей пространства;
- Ролевая система задачи: постановщик, наблюдатель, исполнитель, соисполнитель;
- Удаление аккаунта и пространства;

### 0.3.* - Задачи _(будущая версия)_

- Система спринтов;
- Система тегов;
- Внутренняя система статусов задач: ready, in_progress, done;
- Система фильтров;
- Система трекинга;

### 0.4.* - Коммуникация _(будущая версия)_

- Система напоминаний о задаче (дедлайны);
- Система уведомлений о произошедших событиях и действиях (история);
- Система комментариев к задаче;

### 0.5.* - Интерфейс _(будущая версия)_
