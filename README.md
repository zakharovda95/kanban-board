# Портфолио-проект: «KANBAN BOARD»

Фуллстек веб приложение на NestJS 12 и Nuxt 4.

## Описание

Канбан-доска для совместной работы над задачами. У каждого аккаунта своё пространство: в него можно пригласить других пользователей по инвайт-ссылке. В пространстве роли owner и user с разным набором прав. У задачи свои роли: постановщик, исполнитель, соисполнитель и наблюдатель. Участники сразу видят изменения досок, колонок и задач.

## Цели

Цель проекта - демонстрация архитектуры (см. раздел "Архитектура"), чистоты и качества кода и актуального уровня в
выбранном стеке
технологий (см. раздел "Стек").

## Архитектура

Монорепозиторий из трёх пакетов: Nuxt-фронтенд, NestJS-бэкенд и общий `common` с типами, константами и Zod-схемами. Интерфейс отдаётся с SSR, запросы браузера идут в server-роуты Nuxt и оттуда в REST API, сессия передаётся cookie. Доменная логика бэкенда разложена по модулям, данные хранятся в PostgreSQL через TypeORM. Обновления в реальном времени рассылает Socket.IO: список досок — в комнату пространства, колонки и задачи — в комнату открытой доски.

## Стек

TypeScript, Nuxt 4, Vue 3, Pinia, Tailwind CSS 4, NestJS 12, TypeORM, PostgreSQL, Socket.IO, Zod, Docker.

## Установка и запуск в режиме разработки:

1. Скопировать и заполнить .env файл в зависимости от окружения (шаблон `.env.example`);
2. Установить зависимости (без выполнения npm-хуков) `npm run first-install`;
3. Сбилдить common-проект `npm run build:common`;
4. Поднять инфраструктуру (Docker) `npm run docker:up-infrastructure-dev`:
    - Postgres `localhost:5432` (данные лежат в `./volumes/postgres`);
5. Запустить бэкенд `npm run dev:backend`;
6. Запустить фронтенд `npm run dev:frontend`;
7. Фронт крутится на `FRONTEND_PORT`, API на `BACKEND_PORT` из `.env`;

## Установка и запуск в режиме production:

1. Заполнить `.env.production` (шаблон `.env.example`);
2. Поднять инфраструктуру: `npm run docker:up-infrastructure-prod`;
3. Собрать и запустить приложение: `npm run docker:up-app-prod`;
4. Фронт крутится на `FRONTEND_PORT`, API на `BACKEND_PORT` из `.env`;

## Версии приложения

### 0.1.* - MVP _(текущая версия)_

- Полноценный адаптивный интерфейс приложения со светлой темой и русским языком.
- Одно общее пространство для работы с изменениями в реальном времени (websocket-соединение);
- Базовые действия с досками, колонками и задачами: просмотр, создание, редактирование, удаление, перемещение;

### 0.2.* - Пользователи _(в разработке)_

- Регистрация тестового аккаунта (без подтверждения данных и сбора персональных данных) с ограничениями: пользовательские данные и данные для входа генерируются системой, восстановление данных входа невозможны, аккаунт удаляется через 7 дней;
- Изолированное пространство для работы для каждого аккаунта (до 5 досок на пространство);
- Возможность создавать аккаунты пользователям в своем пространстве (до 5 пользователей на пространство);
- Ролевая система: владелец пространства и участник пространства;
- Гибкая система разрешений и доступов для пользователей пространства: действия над досками/колонками/задачами в зависимости от разрешений (ABAC);
- Удаление пространства и всех данных;

### 0.3.* - Задачи _(будущая версия)_

- Ролевая система: постановщик, исполнитель, соисполнитель, наблюдатель.
- Система спринтов;
- Система тегов;
- Внутренняя система статусов задач: ready, in_progress, done;
- Система фильтров;
- Система трекинга;

### 0.4.* - Коммуникация _(будущая версия)_

- Система напоминаний о задаче (дедлайны);
- Система уведомлений о произошедших событиях и действиях (история);
- Система комментариев к задаче;

### 0.5.* - Интерфейс _(будущая версия)_

- Добавление английской локализации;

### 0.6.* - Инфраструктура _(будущая версия)_
